INDUMISO DESIGN SOLUTIONS WEBSITE

This is a static, responsive website and can be hosted on Netlify, Vercel, GitHub Pages, Cloudflare Pages, cPanel, or any standard web server.

FILES
- index.html
- styles.css
- script.js
- assets/ (portfolio imagery extracted from the supplied IDS corporate profile)

QUICK HOSTING
1. Netlify: drag the entire ids_website folder into Netlify Drop.
2. cPanel: upload the contents of this folder into public_html.
3. GitHub Pages: upload the contents to a repository and enable Pages from the repository settings.

IMPORTANT
- The source document does not provide an email address or domain name, so the website uses the supplied phone number as the primary contact action.
- Before launch, add your preferred domain, business email, social links, analytics, and privacy policy if required.
